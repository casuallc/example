# Message Middleware Examples

消息中间件多语言客户端示例集合。

## 子项目

| 目录 | 说明 |
|---|---|
| `rabbitmq/` | RabbitMQ 多语言 SDK 收发示例（Java Spring Boot / Spring Cloud Stream / Go / .NET 8 / Node.js），统一拓扑可跨语言互通，详见 `rabbitmq/README.md` |
| `rabbitmq-perf-test/` | RabbitMQ 性能测试示例 |
| `jms-client/` | JMS 客户端示例（ADMQ JMS / Jakarta JMS） |
| `tjyj-api-service/` | EMQX/MQTT 相关 API 服务示例（Go） |
| `ibmmq-client/` | IBM MQ 客户端示例（待补充） |
